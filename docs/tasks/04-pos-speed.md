# Task 04: POS Speed and Quick Add

## Goal

ทำให้การรับออเดอร์ซ้ำเร็วขึ้นสำหรับร้านจริง

## Scope

- เพิ่มเมนูขายดี/สั่งบ่อย
- เพิ่ม quick quantity และ repeat last modifier
- เมนูทั่วไปเพิ่มได้ในหนึ่ง action
- modifier ใช้ preset ได้ เช่น Medium Rare + Pepper
- เพิ่มค้นหาเมนูด้วยชื่อหรือ code

## Acceptance criteria

- รายการขายดีเพิ่มได้ไม่เกิน 2 interactions
- modifier preset ทำงานและบันทึก options ถูกต้อง
- ไม่ทำลายราคา/ยอดรวม/receipt เดิม

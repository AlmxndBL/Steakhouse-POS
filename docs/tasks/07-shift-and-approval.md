# Task 07: Shift and Approval Controls

## Goal

ทำให้การเปิดกะ ปิดกะ ส่วนลด และยกเลิกตรวจสอบได้

## Scope

- shift start/end และเงินทอนเริ่มต้น
- cash reconciliation ตอนปิดกะ
- discount presets และ approval threshold
- cancellation/refund ต้องมี reason และผู้อนุมัติ
- เชื่อม audit/report

## Acceptance criteria

- ปิดกะแสดง expected vs actual และ variance
- ส่วนลดเกิน threshold ต้องมี manager/owner approval
- audit log ระบุ user, reason, target และเวลา
